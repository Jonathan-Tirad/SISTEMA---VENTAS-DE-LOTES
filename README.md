# SISTEMA---VENTAS-DE-LOTES
Sitema de lotes

## Empresa
Terrenos del Norte S.A.C.

## Objetivo
Desarrollar un sistema modular en Python
para registrar lotes y gestionar sus ventas.

## Requisitos
- Python 3.
- Visual Studio Code.

## Archivos del proyecto
- main.py: menu principal.
- lotes.py: registro y listado de lotes.
- validaciones.py: validacion de datos.
- ventas.py: registro y resumen de ventas.
- calculos.py: calculos economicos.

## Funcionalidades
1. Registrar lotes.
2. Listar todos los lotes.
3. Consultar lotes disponibles.
4. Registrar ventas.
5. Calcular cuota inicial del 20%.
6. Calcular saldo pendiente.
7. Evitar ventas duplicadas.

## Ejecucion
Abrir la terminal y ejecutar:

python main.py

## Pruebas
- Registro correcto.
- Calculo de venta.
- Ingreso de datos invalidos.
- Prevencion de ventas duplicadas.
